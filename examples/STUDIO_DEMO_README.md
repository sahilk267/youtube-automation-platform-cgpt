# Studio demonstration — simulated NFL-style tactical diagram

All visual assets (field sketch, arrows, picture-in-picture insert, captions) are **original technical illustrations**. No real game footage or player statistics are shown. The English audio was generated locally using eSpeak for demo purposes; **it is not professional narration** and its timing has not been verified by a forced aligner. The source MP4 contains no music or licensed external sports footage.

Use `examples/create_m2_demo.py` to rebuild visuals (supply a compatible voice WAV or omit it for a silent preview). The static screenshot illustrates a middle scene at roughly 4 seconds.

Files: `studio_m2_demo.mp4`, `studio_m2_frame.png`, `studio_m2_plan.json`, `studio_m2_qc.json`.

Do not publish the sample on a public channel without editing, human fact/rights review, suitable high-quality narration and independent YouTube policy review. This is a development benchmark, **not a viral video**.

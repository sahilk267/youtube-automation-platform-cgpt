# PRODUCTIVITY — Expert Creative Director v3.0

**Binding:** `domain_id=productivity`; implement as **policy + specialist domain algorithms**, never a duplicate renderer. `core/21_EVIDENCE_TO_SCREEN_V3.md` and strict `contracts/v3` govern shared artifacts. **Status: SPECIFIED, NOT IMPLEMENTED.**

## Audience and unique creative objective
People who want measurable improvements to workflows rather than untested productivity hacks.

## Source/evidence prerequisites
Recorded baseline times, repeatable workflow tests, accessible documentation and user-provided tasks/data.

## Honest opening (not boilerplate)
State a realistic bottleneck and a testable result with transparent conditions.

## Story sequence / exact decision policy
1. Show actual repetitive task/baseline.
2. Explain process and controls.
3. Demonstrate automation or alternative with real screen capture.
4. Compare effort/time, errors and edge cases.
5. Summarize reusable workflow and costs.

## Approved screen grammar
- Original screen-recorded workflow with personal information redacted
- Before/after timer and source notes
- Flow diagram of manual vs automated decisions
- Reproducible checklist and exception path

## Voice/audio policy
- Pragmatic, calm and precise tool instructions
- Avoid claims of miraculous productivity without actual measurement

## Text, data and overlay rules
- Input size, time, error count and hardware version
- Optional step text and failure states

## Allowed narrative formats (requires format-pack validation)
`DEMO_REVIEW`, `STEP_LESSON`, `CASE_STUDY`, `SHORT_EXPLAINER`

## Payoff and ending
Net measurable result, maintenance caveat and reusable template.

## Mandatory exception and accuracy gates
- Data privacy, unreliable automation and access permission scope
- No invented time saved or fake stopwatch

## Local compute mode
**CPU without dedicated GPU:** Real UI recording, process diagrams and time-series charts.
**Optional future GPU:** Optional explanatory animation; efficiency test must remain actual.

## Golden fixture and independent manual acceptance
Catch speed comparison different baselines and unreported automation failures.

A human reviewer must inspect actual rendered Short and long-form from this director for factual/rights accuracy, sound, screen readability, novelty, pacing, start/end payoff. Tests must show a difference from other category outputs **beyond swapped fonts/colors/voice**. Record inputs and source URLs; do not invent viewer retention.

# TECHNOLOGY — Expert Creative Director v3.0

**Binding:** `domain_id=technology`; implement as **policy + specialist domain algorithms**, never a duplicate renderer. `core/21_EVIDENCE_TO_SCREEN_V3.md` and strict `contracts/v3` govern shared artifacts. **Status: SPECIFIED, NOT IMPLEMENTED.**

## Audience and unique creative objective
Practitioners seeking truthful demonstrations, reproducible benchmarks, workflow decisions and clear limitations.

## Source/evidence prerequisites
Versioned vendor docs, changelogs, actual local test environment and reproducible commands with secrets redacted.

## Honest opening (not boilerplate)
A real user problem and falsifiable claim: “Does this work on a CPU-only laptop?”

## Story sequence / exact decision policy
1. State test hardware/version, scope and criterion.
2. Show real installation/capture, not a generated UI.
3. Execute test and show observed output including failure.
4. Compare meaningful alternatives with equal measurement method.
5. Recommend for precise use case and list limitations.

## Approved screen grammar
- Authentic screen recording with secret redaction and cursor focus
- Split-screen test outputs with exact versions and elapsed time measured
- Terminal/code overlays only from actual execution
- Diagram data flow and actual benchmark chart

## Voice/audio policy
- Instructional voice with pauses while menus/commands visible
- Pronounce version names, units and tool acronyms consistently

## Text, data and overlay rules
- Environment/version/hardware/source labels
- Step number, actual command and result, not fictitious demo logs

## Allowed narrative formats (requires format-pack validation)
`DEMO_REVIEW`, `STEP_LESSON`, `SHORT_EXPLAINER`, `LONG_DOCUMENTARY`

## Payoff and ending
Reproducible steps, practical recommendation and limitations.

## Mandatory exception and accuracy gates
- Never claim a product was hands-on tested when it was not
- Protect keys, credentials, personal data and licenses in screencast

## Local compute mode
**CPU without dedicated GPU:** Original captures, cropped readable code, flowcharts, real result exports.
**Optional future GPU:** Optional cinematic concept b-roll separately labeled, not fake screenshots/results.

## Golden fixture and independent manual acceptance
Catch benchmark conditions mismatch, fabricated console output and secret leakage.

A human reviewer must inspect actual rendered Short and long-form from this director for factual/rights accuracy, sound, screen readability, novelty, pacing, start/end payoff. Tests must show a difference from other category outputs **beyond swapped fonts/colors/voice**. Record inputs and source URLs; do not invent viewer retention.

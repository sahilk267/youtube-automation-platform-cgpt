# FORMAT — GAMEPLAY_ANALYSIS (v3.0)

**Purpose:** Genuine game capture/challenge with source/version/permission and analysis.

**Narrative logic:** Show challenge -> authentic attempt -> mechanics explanation -> observable outcome -> takeaway.

**Editing and asset rules:** No synthetic gameplay implied to be real and no third-party streamer clips without rights.

**Duration and delivery:** Choose time using content complexity and observed audience context, not mandated 2-second cut cadence. Shorts and long-form require distinct aspect profiles, composition and meaningful content; no promise that arbitrary runtime boosts reach.

**Audio/text:** Narration must match action or screenshot. Subtitles and semantic evidence overlays are separate; render with native-language fonts. Background sound must have rights and should duck under dialogue. Ending must resolve the opening promise.

**Quality and fail state:** Publisher rules and game capture provenance reviewed. Missing rights/source/actual demonstration -> `BLOCKED`. Final viewing/approval is required for representative video. Format rules never override domain factual rules or source permissions.

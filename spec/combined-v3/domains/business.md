# DOMAIN-BUSINESS — Corporate Intelligence and Markets OS

**ID:** `business` | **Edition:** Ultimate | **Purpose:** explain companies, economics, governance, competitive position and historical outcomes using reproducible numbers and primary filings.

## Entities and permitted evidence

Legal entity, jurisdiction, reporting currency, audited period, annual/quarterly filing, line item, ownership percentage with as-of date, subsidiary, business segment, unit economics, market source, competing company, strategy, contract, claim/forecast, risk factor. Prefer stock exchange/regulator/company filings and verified public information. Paid data unavailable -> explicit coverage gap. Not personalized investment advice.

## Engines

| Engine | Inputs -> steps -> output |
|---|---|
| Filing Intake | Company legal ID -> official filed financials, signed/unaudited distinctions, footnotes, correct currency and reporting period -> source records |
| Financial Normalizer | Statements -> harmonize revenue, expenses, cash flow, balance sheet, one-time items, fiscal periods and units -> reconciled table |
| Arithmetic Auditor | Tables -> balance/ratio/growth reconciliation, divide-by-zero and unit check, period comparability -> verified numeric claims |
| Ownership/Influence | Dated filings -> ownership/control edges with percentages and date; no conspiracy inference -> provenance graph |
| Unit Economics | Observed customer/revenue/cost measures -> formula assumptions and sensitivities -> scenario report |
| Competitive Landscape | Competitors, market region, periods -> comparable business models/metrics and source limitations -> position analysis |
| Forecast & Sensitivity | Owner/study assumptions -> explicit scenarios, variance and risk bands -> **not** actual facts or promised stock returns |
| Governance/Adversarial | Allegations, conflicts, controversies -> documents, alternative explanations, legal/human review -> responsible dossier |

## Operation

Discover corporate event -> verify legal entity/period -> fetch filings/records -> parse calculations -> check source independence -> compare context -> challenge forecasts -> script transparent explanations -> original charts -> QA source figures and units -> manual review for material accusations -> publish. Calculated values carry formula, input IDs, currency conversion date and rounding protocol. Revenue forecasts cannot mix with observed audited results.

## Evaluation

FY vs calendar year confusion, thousands vs millions currency mistake, negative cash flow presented as profit, pre-tax vs after-tax conflation, exchange rate absent, informal ownership claim, allegation without due process, affiliate disclosure omitted and stale filings. Release requires zero silent numerical source mismatches in golden fixtures.

# DOMAIN-CAREER — Career Paths and Skills Intelligence OS

**ID:** `career` | **Edition:** Ultimate | **Mission:** credible career/skills education with region-specific, time-dated evidence and practical plans. No guaranteed job or salary.

## Ontology and evidence

Occupation, region, currency, experience tier, job listing age/provider, skill competency, credential accreditation, tuition/cost, employment type, employer, wage dataset/survey methodology, portfolio artifact, interview skill, progression path. Respect private résumé/person data and user consent; don't scrape protected job boards.

## Engines

| Engine | Input -> method -> artifact |
|---|---|
| Labor Demand Radar | Permitted region/time-scoped job data -> dedupe listings, infer skills trends only within sampled coverage -> dated demand report |
| Salary Context Validator | Official/survey data -> currency, period, location, median/range/sample bias -> caveated estimate, not promise |
| Skill Graph | Job role -> verified skill prerequisites and pathway dependencies -> roadmap |
| Credential Verifier | Course/certification claim -> provider accreditation/expiry/cost and original evidence -> credential note |
| Practical Project Lab | Skill objective -> portfolio project with checkable deliverables and rubrics -> course content |
| Interview/Resume Coach | User-consented data -> role-specific practice, accuracy and privacy review -> guidance draft |
| Career Risk Reviewer | Employment/visa/legal claims -> jurisdiction/date check, uncertainty, regulated specialist review -> risk flags |

## Workflow

Choose market/role/persona -> retrieve dated official/permitted evidence -> normalize postings/salaries and sample caveats -> identify learning gap -> create stepwise plan with projects -> validate examples -> educational visuals and captions -> editorial QA -> publish -> learn from viewer questions without treating anecdotes as representative statistics.

## Safeguards and evaluation

Do not advertise specific jobs as open unless actual authoritative posting and timestamp; do not invent placements/salaries or claim income guarantees; protect job seeker identities. Tests: obsolete credential, fake vacancy, annual/monthly salary confusion, US vs India currency/seniority mix, unsafe scraped personally identifiable data, misleading remote-work claim.

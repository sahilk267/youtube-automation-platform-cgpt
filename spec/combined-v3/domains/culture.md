# DOMAIN-CULTURE — Internet Culture, Media and Social Context OS

**ID:** `culture` | **Edition:** Ultimate | **Goal:** investigate origin, evolution, context and influence of internet trends with careful provenance and respect for creators and communities.

## Ontology

Meme/phrase, media origin, creator permission, first observed timestamp, platform, localized variation, cultural context, diffusion edge, claim vs joke, internet community, translation, controversy, public response, synthetic/altered status. Viral shares are evidence of diffusion, not truth about underlying claims.

## Engines

| Engine | Input -> procedure -> output |
|---|---|
| Trend Origin Tracker | Observed remix/phrase -> timestamped earliest accessible source search and alternate origins -> provisional provenance graph |
| Diffusion Map | Permitted cross-platform posts -> known repost/quote clusters, geography/language and uncertainty -> spread diagram |
| Cultural Context Analyzer | Region/language norms -> explain references, humor, alternative meanings, avoid stereotyping -> context memo |
| Myth/Misinformation Critic | Viral narrative -> source vs opinion/satire and fact-checking -> evidence dossier |
| Creator Attribution/Rights | Origin assets -> original creator/license/permissions and remix status -> rights review |
| Harassment/Privacy Gate | Individuals/community posts -> minimize personal data, do not amplify doxxing/harassment -> safe editorial plan |
| Internet Story Director | Provenance + cultural meaning -> chronology, why it spread, distinct original commentary, measured uncertainty -> script |

## Workflow

Discover emerging meme -> capture only permitted source snapshots -> investigate original timestamps without promising first-ever post -> verify context and creator attribution -> triangulate discussions -> script origin/migration/commentary -> use licensed remixes or original illustration rather than unlawful copied clip -> QA privacy and citation -> publish -> corrections if earlier origin emerges.

## Tests

Earliest collected post declared definite origin, satire treated as fact, edited video not labeled, private minor exposed, creator material reused without permission, national/cultural stereotyping, copied viral video with only watermark/crop.

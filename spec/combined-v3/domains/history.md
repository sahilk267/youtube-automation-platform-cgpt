# DOMAIN-HISTORY — Primary Archives and Historical Reconstruction OS

**ID:** `history` | **Edition:** Ultimate | **Goal:** timelines and explanations grounded in archival records and scholarship, with precise treatment of contested narratives.

## Ontology

Historical actor, polity, date/calendar, geography and historical borders, original-language document, manuscript/edition, source provenance, archaeological artifact, witness account, secondary historian, school of interpretation, reconstruction confidence, disputed event. Do not retroject modern borders, names, motives or norms without period context.

## Engines

| Engine | Inputs -> steps -> outputs |
|---|---|
| Archive Explorer | Date/person/event variants -> permitted museum/library/archive catalogs, primary documents, translations, revision metadata -> source dossier |
| Provenance & Authenticity | Document/photo -> archive ID, publication date, edition, author, translation lineage, possible forgery warnings -> authenticity record |
| Chronology Builder | Dated claims -> convert BCE/CE/calendars with documented assumptions, precision ranges and event ordering -> timeline |
| Historical Geography | Place/time IDs -> period-specific borders/map sources, change over time and uncertain locations -> map specification |
| Historiography Challenger | Primary sources + academic debate -> alternative interpretations, source biases, consensus/disagreement -> perspective matrix |
| Myth Checker | Popular historical assertion -> source trail, first appearance and verified conflicting records -> bounded verdict |
| Translation Reviewer | Original text + multiple translations -> passage alignment and context; critical quotes require human bilingual review -> quote record |
| Reconstruction Director | Sourced event + era constraints -> period-appropriate visuals labeled as reconstruction, not actual archive -> scene policy |

## Investigation protocol

Start with question, geographic/time boundaries and event definition; locate primary records; identify their provenance and author motives; distinguish contemporary records from modern scholarship; separate consensus from controversy; build consistent dates, units and maps; script evidence and uncertainty; illustrate with licensed archival media and clearly marked reconstructions. Missing primary archives => disclose and avoid categorical “history proves” language.

## Automation and safeguards

Automate archive indexing, source comparisons, dated timelines and illustrations. Flag contested historical identity, genocide/atrocity denialism, fabricated quotes and politicized claims for human evidence and harm review. No artificial reenactment presented as actual film. Rights for museum/archive photos and scans require checking individually.

## Fixtures

Gregorian conversion off-by-one, BCE year zero, translation with altered meaning, anachronistic flag/map, photo dated decades later, one primary biased narrator treated as consensus, incorrectly attributed quote, reconstructed battle footage without label.

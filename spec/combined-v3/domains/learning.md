# DOMAIN-LEARNING — Pedagogy, Curriculum and Education Intelligence OS

**ID:** `learning` | **Edition:** Ultimate | **Aim:** measurable learner understanding, not just polished explanations.

## Domain knowledge

Learner persona and prior knowledge, learning objective, prerequisite, misconception, concept map, worked example, practice task, assessment rubric, accessibility requirement, difficulty level, video chapter, comprehension feedback. Audience analytics cannot directly prove learning; use opt-in quiz/test when available.

## Engines

| Engine | Input -> behavior -> artifact |
|---|---|
| Objective Decomposer | Topic and learner level -> observable learning objectives and scope |
| Prerequisite Mapper | Objectives -> prerequisite DAG and missing knowledge checks |
| Misconception Finder | Curriculum and known learner errors -> common false intuitions with corrected examples and evidence |
| Lesson Planner | Objective graph -> hook/problem, explanation, guided worked example, practice, summary |
| Example Generator | Verified principles -> multiple difficulty graded original worked examples with checkable solutions |
| Assessment Builder | Objectives -> answerable quizzes/exercises with explicit answer keys and rationale |
| Explanation Critic | Draft -> detect unexplained terms, circular definitions, false simplification, cognitive overload |
| Accessibility/Layout Director | Lesson -> readable visuals, captions, pacing, language/glyph checks |
| Learning Outcome Reviewer | Quiz/feedback -> report observed comprehension, gaps and uncertain samples without overclaim |

## Workflow

Select topic and target learner -> map prerequisites -> source-check facts -> plan lesson objective -> generate worked examples -> independently check every solution -> storyboard diagrams -> CPU render or GPU when installed -> subtitle/accessibility QA -> user/editorial check -> publish and optionally gather quizzes/learner feedback. Distinguish conceptual explanation from credentialed training.

## Safeguards

No fabricated syllabus/official examination changes or guaranteed jobs/grades. Medical/legal/financial educational content needs proper domain caveats. Human review if examples could mislead or harm. Persist learning materials with version and correction propagation.

## Golden tests

Lesson assumes missing prerequisite; math worked example yields wrong final answer; subtitle hides formula; unsupported official exam fact; misleading before/after learning efficacy claim; quiz answer key contradicts explanation.

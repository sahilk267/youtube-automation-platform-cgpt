# DOMAIN-PRODUCTIVITY — Workflow, Automation and Performance Intelligence OS

**ID:** `productivity` | **Edition:** Ultimate | **Mission:** practical, measured productivity improvements, not unsupported “10x life hacks.”

## Ontology

Task, workflow graph, tool/license, baseline measure, intervention, observed duration, quality metric, error/rework, automation permission, energy/cognitive load, reproducibility record, privacy boundary, before/after environment. No unauthorized account actions.

## Engines

| Engine | Inputs -> algorithm -> output |
|---|---|
| Workflow Recorder | Owner-created workflow steps -> duration, handoffs, constraints, failure count -> baseline |
| Bottleneck Finder | Task DAG and measured samples -> critical path and waiting/rework analysis -> ranked issues |
| Automation Planner | Bottleneck + approved tools -> reversible safe automation proposal and permissions -> implementation spec |
| Before/After Evaluator | Same task conditions before/after -> reproducible timing/quality comparison, confounders and variance -> observed effect |
| Template Designer | Verified workflow -> original checklists/automation templates with usage instructions -> downloadable companion |
| Tool Comparator | Installed/tested tooling -> setup cost/privacy/performance/permissions -> factual evaluation |
| Habit Evidence Reviewer | Behavioral research -> avoid shaky psychological claims, describe study limitations -> evidence notes |

## Pipeline

Collect question -> define baseline and success metric -> test changes in sandbox or owner-approved environment -> measure actual repetitions -> analyze confounders -> script demonstration with measured evidence -> original screen recording/graphics -> QA source/license/privacy -> publish. Automation must not execute destructive or privileged actions without explicit consent.

## Tests

Single anecdotal stopwatch reported as universal effect, hidden tool subscription, leaking credentials through screen capture, script deletes files, before/after tasks have unequal scope, cached demo result presented as new observation. All flagged.

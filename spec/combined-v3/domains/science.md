# DOMAIN-SCIENCE — Scientific Research OS

**ID:** `science` | **Edition:** Ultimate | **Purpose:** interpret research faithfully, distinguish actual findings from hype and explain mechanisms through accurate visuals.

## Ontology and content

Entities: paper/DOI/preprint version, author, institution, journal, study population, intervention/exposure, comparison, outcome, effect size, confidence interval, sample size, statistical method, replication, retraction, field consensus. Formats: study deep dive, myth/claim check, experiment explainer, animated mechanism, scientist interview analysis. Scientific curiosity must not become manufactured certainty.

## Engines

| Engine | Input -> evidence-anchored process -> output |
|---|---|
| Paper Discovery | Query/title/DOI -> retrieve journal/preprint/version/retraction/correction status from permitted metadata and full text where licensed -> source versions |
| Methods Examiner | Article -> identify study design, controls, power/sample, confounders, outcome prespecification, limitations -> method quality checklist |
| Quantitative Calculator | Reported sample/effects -> independent reproducible numerical check of units, percent vs percentage points, CI/ratios/statistical assumptions -> calculation record |
| Replication & Consensus | Papers/reviews -> distinguish one study, meta-analysis, guidelines, replication, disputed evidence and field scope -> calibrated context |
| Mechanism Explainer | Verified phenomena -> causal chain with explicit known vs theoretical steps -> diagrams/analogies with scientific review |
| Retraction Monitor | DOI/version index -> detect erratum, retraction or changed claim; invalidate affected videos/research memory -> review task |
| Scientific Visualizer | Parameterized data -> chart, physically possible illustration, scale legend, uncertainty band -> graphics manifest |
| Adversarial Scientific Reviewer | Draft -> strongest alternative explanation, methodology weakness and scope overreach -> critique record |

## Workflow

Discovery -> primary paper metadata -> publication status -> study design -> correct numerical interpretation -> independent replication/consensus survey -> limitation extraction -> source-backed script -> scientifically honest visualization -> QA -> editorial approval -> track updates. If full paper inaccessible, label abstract-only assessment. Preprint != peer reviewed; association != causation; p-value != effect size or certainty. Reproduced calculation != reproduced experiment. Avoid research advice that poses as individualized medical care.

## Automation contract

Routine retrieval, extraction, calculation and charts automated subject to data validity. Expert review required for consequential health/safety conclusions, contested consensus or alleged fraud. A failed data check blocks claim, not silently corrected by plausible number.

## Evaluation fixtures

Sample-size misquote, retracted study, preprint mistaken for published, confounding mistaken for cause, two different measurement units, non-independent review citations, overstated animal-to-human implications, erroneous scale animation. Each must be caught or flagged for human review.

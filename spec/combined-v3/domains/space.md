# DOMAIN-SPACE — Astronomy, Space Missions and Physics Intelligence OS

**ID:** `space` | **Edition:** Ultimate | **Mission:** accurate missions, astronomy discoveries, cosmic-scale explanations and high-quality scientifically responsible motion graphics.

## Entities

Mission, agency, spacecraft, launch vehicle, instrument, orbit/epoch, observation, sky object, distance, mass, time, uncertainty interval, paper/catalog version, image asset processing history, mission timeline, speculative hypothesis. Distinguish press images, composite false-color imagery, artist impressions, observations and simulations.

## Engines

| Engine | Input -> action -> output |
|---|---|
| Mission Monitor | Permitted agency mission updates, launch windows, delay records -> versioned dated milestone timeline |
| Observation/Paper Research | Official mission data/peer-reviewed papers -> measured discovery vs interpreted theory, version/retraction -> evidence map |
| Orbital/Unit Validator | Published ephemeris and units -> dimensional sanity checks and period/scale calculations using validated library/data -> calculation manifest |
| Cosmic Scale Graphics | Distance/mass/time numbers -> scale-aware schematic with labels and unavoidable distortions disclosed -> animation |
| Imaging Provenance | Telescope image -> actual observation, processed composite, color mapping, source licensing and credits -> asset provenance |
| Space Myth Checker | Popular viral “planet near earth” claim -> dated astronomical source comparison, exaggeration critique -> verdict |
| Mission Timeline Director | Verified stages -> chronological documentary scene order, uncertainties and latest status -> narrative plan |
| Physics Critic | Script/visual -> conservation/units/context review and obvious physically false depictions -> QA report |

## Pipeline

Discover mission event -> verify agency record/status timestamp -> gather technical source and numerical context -> perform validated calculations -> choose explanatory scale (accurate where possible; explicitly not-to-scale when necessary) -> scientifically reviewed storyboard -> original diagrams/labels -> captioned render -> source-specific QA. A simulation or AI animation is not observational footage.

## Automation

Automate official update intake, numeric validators, diagrams and content planning. Human specialist review for dramatic claims (“life discovered”, new physics, imminent impact), pending observations, and disputed scientific announcements. Launch window changes should invalidate scheduled date/time scenes.

## Tests

AU vs light-year conversion, orbital period units, artistic image mistaken for telescope photo, canceled mission launch left scheduled, simulated planet image labelled as actual, wrong historical spacecraft chronology, overconfident exoplanet habitability.

# Gaming OS — REAL GAMEPLAY & PATCH-AWARE ANALYSIS

1. Resolve game edition, region/platform, current patch, mechanics and publisher policy; track patch note updates.
2. Ingest **original or rights-cleared** capture/replay metadata; validate provenance and timestamps; never invent gameplay success based on AI-generated clip.
3. Detect highlights and measure events against replay/video data (where permitted), not arbitrary engagement predictions.
4. Test strategies in a reproducible match/training setup or label them hypotheses; keep settings, build, difficulty and hardware.
5. Build fun narrative and edits with spoiler/time warnings and fair commentary; respect game publisher audio/footage streaming terms.
6. Output: gameplay timeline, validated mechanic/patch claims, strategy tests and clip rights sheet. Patch revisions invalidate stale tips.

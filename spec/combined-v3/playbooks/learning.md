# Learning OS — OBJECTIVE-BASED INSTRUCTION

1. Identify viewer prerequisite knowledge, locale, learning goal and constraints; decompose into observable objectives and prerequisite graph.
2. Find common misconceptions using reliable pedagogy and feedback data, not invented survey numbers.
3. Generate worked examples, counterexamples, progressively harder exercises and formative questions with answer verification (deterministic where possible).
4. Validate that narration, illustrations and subtitles are accessible and paced for comprehension. Preserve learning objective across short and long formats.
5. Feedback loop measures quiz/learning outcomes only when actual data supplied; watch time alone is not proof of learning.
6. Outputs: learning plan, solution checks, accessible scenes, optional assessments and reviewer rubric.

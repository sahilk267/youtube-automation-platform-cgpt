# Space OS — MISSION DATA, PHYSICS AND SCALE

1. Collect mission announcements, ephemerides, agency observations, images and papers with source/time metadata.
2. Verify unit conversions and orbital calculations using tested physics functions and source constants; report reference frame, uncertainty and epoch. Never use aesthetically convenient nonphysical scale without label.
3. Differentiate detected observations, theoretical inference, mission plan and speculative concept art. Track changed launch schedules and scientific corrections.
4. Generate original labeled orbit/scale diagrams and cinematic visualizations with accurate disclaimers about compression and artistic rendering.
5. Outputs: mission timeline, calculation log, provenance-linked image pack, modeling assumptions and science QA.

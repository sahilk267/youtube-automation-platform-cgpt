## U.1 Non-negotiable north star

ViralOS is an original, evidence-first, commercially sustainable **YouTube intelligence and production operating system**, owned and tested on user's own channels first. ## U.4 Complete deep automation pipeline

```
PERMITTED SOURCE SIGNAL / USER IDEA
  -> source coverage and collector state
  -> topic cluster + freshness/time series
  -> federated domain assignment + Editorial Decision Council
  -> research plan with explicit source policy, depth, budget and stop checks
  -> source retrieval/archiving, primary records and source independence
  -> atomic claims + citations + domain-specific tools/calculations
  -> adversarial review, contradictions, gaps and sensitivity/risk
  -> audience intent + original story angle + format portfolio check
  -> script versions + source-to-line mapping and quality/editorial checkpoints
  -> cinematography & visual policy -> SceneSpecs + rights
  -> CPU diagrams/recordings or model-licensed GPU image/video shot generation
  -> voice, motion, SFX/music rights, captions and FFmpeg timeline
  -> temporal/video/audio QC + source/rights/originality/disclosure gates
  -> human approval where required; optional opt-in low-risk trusted publish
  -> export/resumable official upload and schedule
  -> authorized Analytics snapshots and actual income ledger
  -> disciplined experiments, source corrections, memory + improvement lab
```

Every arrow is a versioned job dependency. Each node must be cancellable/recoverable, report missing inputs, and produce typed artifacts and reason codes. Model-only opinion cannot pass evidence gate; missing source/rights prevents unsafe downstream actions. On high-stakes news, automation produces *case file*, not independent legal/political verdict.

## U.5 Professional generation: beyond prompt text

CPIE canonical Shot/SceneSpec retains subject, framing, lens style, lighting, motion of camera and subject, physical constraints, aspect/duration, source claims, asset rights, consistency references, dialogue/subtitles, model capability requirements, seed/negative constraints and review status. Individual shots may be locally generated with compatible visual model from an approved registry; consistency through character/prop/location bibles and reference assets; test temporal flicker/identity drift/scene continuity and real-world factual depiction. Editing pipeline stitches short shots; never promise unbounded 4K cinematic footage solely due to GPU RAM.

**Science/history/newsroom:** realistic depiction is not evidence. Generated scientific diagrams label simplifications; historic reconstructions distinguished from archival footage; journalism never synthesizes an event to pass off as genuine recording. Sports authentic original tactical charts replace unknown-rights highlights by default.

## U.6 Hardware scaling without rewrite

- On current i7/32GB/no GPU, use full research/planning/CPU video and optional small quantized models with bounded concurrency.
- On RTX 3090 24GB, compatible visual/audio models added via optional CUDA worker, with measured VRAM/memory/offload needs and bounded shot length.
- On RTX A6000 48GB or newer/multi-GPU, admission can permit larger compatible workflows, distributed research and media workers; model/support determined by verified manifest.
- All hardware modes share same `project_id`, `SourceVersion`, `SceneSpec` and render versions. New GPU simply adds adapter, model registry entries and a new render attempt; no duplicate DB or “ultimate-only” different project format.

## U.7 Domain-specific quality mastery is measured

A domain is **not implemented** unless it has 12-domain federation manifest, working source adapters from permitted sources, domain-specific verifiers/calculators, at least one authentic traceable example, negative/adversarial golden fixtures, unique visual grammar, rights gate and actual end-to-end render/export. Source availability limits must be explicit. A headline paraphraser with domain prompt is not a domain OS.

Every released subengine reports citation correctness, numerical accuracy, coverage gaps, contradiction false positives, source independence, originality, technical QC, human editorial acceptance, platform claim rate and actual audience feedback. New prompts/model versions require regression tests and human sampling; no unbounded autonomous self-modifying production code.

# FORMAT — BREAKING_BRIEF (v3.0)

**Purpose:** Timestamped verified update with risk-aware information boundary.

**Narrative logic:** Confirmed event -> exact source date/time -> what changed -> what is unconfirmed -> concise next verified update.

**Editing and asset rules:** No speculative sensational headline or stale data presented as live; high-risk subject needs owner approval.

**Duration and delivery:** Choose time using content complexity and observed audience context, not mandated 2-second cut cadence. Shorts and long-form require distinct aspect profiles, composition and meaningful content; no promise that arbitrary runtime boosts reach.

**Audio/text:** Narration must match action or screenshot. Subtitles and semantic evidence overlays are separate; render with native-language fonts. Background sound must have rights and should duck under dialogue. Ending must resolve the opening promise.

**Quality and fail state:** Freshness warning + change invalidation mandatory. Missing rights/source/actual demonstration -> `BLOCKED`. Final viewing/approval is required for representative video. Format rules never override domain factual rules or source permissions.

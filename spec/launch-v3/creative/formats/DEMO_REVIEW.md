# FORMAT — DEMO_REVIEW (v3.0)

**Purpose:** Original hands-on test with conditions, limitations and reproducible outcome.

**Narrative logic:** Problem -> real test setup -> authentic recording -> results -> comparison -> limits.

**Editing and asset rules:** Do not substitute synthetic UI screenshots or invented benchmarks for measurements.

**Duration and delivery:** Choose time using content complexity and observed audience context, not mandated 2-second cut cadence. Shorts and long-form require distinct aspect profiles, composition and meaningful content; no promise that arbitrary runtime boosts reach.

**Audio/text:** Narration must match action or screenshot. Subtitles and semantic evidence overlays are separate; render with native-language fonts. Background sound must have rights and should duck under dialogue. Ending must resolve the opening promise.

**Quality and fail state:** Redaction, copyright/credential scan and actual playback comprehension check. Missing rights/source/actual demonstration -> `BLOCKED`. Final viewing/approval is required for representative video. Format rules never override domain factual rules or source permissions.

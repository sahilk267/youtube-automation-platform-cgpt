# FORMAT — REACTION_REVIEW (v3.0)

**Purpose:** Original criticism/commentary as the product, not source clip redistribution.

**Narrative logic:** Context + rights gate -> source excerpt if authorized -> original analysis with annotation -> source-backed conclusion.

**Editing and asset rules:** A new voiceover/face or zoom alone never establishes rights/originality; in-app Remix is manual handoff.

**Duration and delivery:** Choose time using content complexity and observed audience context, not mandated 2-second cut cadence. Shorts and long-form require distinct aspect profiles, composition and meaningful content; no promise that arbitrary runtime boosts reach.

**Audio/text:** Narration must match action or screenshot. Subtitles and semantic evidence overlays are separate; render with native-language fonts. Background sound must have rights and should duck under dialogue. Ending must resolve the opening promise.

**Quality and fail state:** Human full clip/context & source-use review required; unresolved rights fail closed. Missing rights/source/actual demonstration -> `BLOCKED`. Final viewing/approval is required for representative video. Format rules never override domain factual rules or source permissions.

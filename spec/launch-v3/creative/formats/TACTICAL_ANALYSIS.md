# FORMAT — TACTICAL_ANALYSIS (v3.0)

**Purpose:** Sports-specific verified game state and original explanatory visualization.

**Narrative logic:** Source match state -> field diagram -> decision alternatives -> factual outcome -> takeaway.

**Editing and asset rules:** No default unlicensed match highlight; visual arrows are sourced or labeled hypothetical.

**Duration and delivery:** Choose time using content complexity and observed audience context, not mandated 2-second cut cadence. Shorts and long-form require distinct aspect profiles, composition and meaningful content; no promise that arbitrary runtime boosts reach.

**Audio/text:** Narration must match action or screenshot. Subtitles and semantic evidence overlays are separate; render with native-language fonts. Background sound must have rights and should duck under dialogue. Ending must resolve the opening promise.

**Quality and fail state:** Sports stat and rule fixtures mandatory, 9:16 reframe tested. Missing rights/source/actual demonstration -> `BLOCKED`. Final viewing/approval is required for representative video. Format rules never override domain factual rules or source permissions.

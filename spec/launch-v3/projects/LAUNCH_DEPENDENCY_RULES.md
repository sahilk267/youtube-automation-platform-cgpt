# Launch Standalone Dependency Rules

This pack is runnable as a **specification handoff** without Ultimate ZIP, not a runnable app. Only `sports` and optional `technology` domain dossiers are carried; remaining 10 are reserved identifiers and must never appear active in UI. Shared registries include GPU expansion stubs but dedicated GPU is not required and GPU inference must not run in this profile. Historical v2 acceptance rows `U-*` are deferred references, not release blockers. Full future plans remain in Ultimate/Combined packs.

# Deployment and authorization policy — ULTIMATE

Initial OS: Windows on i7-8th-gen / 32GB RAM / no dedicated GPU; source data and user projects persisted locally. Only owner-operated YouTube monetization is in scope until an explicit separate decision. GPU and API credentials are optional, not fabricated. Localhost only by default.

**Edition:** `ULTIMATE`. Launch CPU research+graphics+manual exports is the baseline. Ultimate domain and image/video features require their individual licensed source/model access, tests and hardware. No assumption of monetization approval.

**Mandatory approval:** serious allegations, protected personal information, misleading synthetic realism, unknown rights, sensitive medical/financial claims, legal threats, downstream corrections, public publishing when trusted channel mode not explicitly authorized.

**Default controls:** PRIVATE publication visibility; no hidden uploads; no automatic external model download; no account/password storage in plaintext; fail-open forbidden for source verification and footage licensing.
